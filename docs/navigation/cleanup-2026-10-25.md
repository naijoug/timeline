# Shared navigation cleanup · 2026-10-25

## Evidence and scope

The supplied desktop screenshot shows two identical collapse controls: beside the sidebar wordmark and in the fixed header. The same duplication was reproduced on the public homepage in dot's cloud Chromium. The long rail also repeated the home destination as “所有主题” and “浏览主题”, and offered a search field for only four visible topics.

This change keeps one desktop collapse/expand button in the persistent header. Phones retain their distinct app Back and menu controls, with one close button inside the modal drawer. It removes the duplicate sidebar control, the small topic-name filter, the repeated discovery link, and a noninteractive language placeholder. All four themes remain directly visible; actual event search, filters, stored reading state, links and history behavior are unchanged.

The narrower rail aligns brand/navigation spacing, gives the appearance action a text label and current mode, and preserves accessible names in icon-only mode. Home spacing and heading size are gently reduced. Fira Code, monochrome palettes, sticky navigation, timeline leaf layouts and compact client indexes are unchanged.

## Checks

- Unit regression: exactly one desktop toggle; accessible icon-only topic labels; mobile controls kept separate.
- Production bundle DOM checks: repeated desktop toggles update aria state and storage; mobile Escape restores focus and background; resizing a drawer to desktop closes it and focuses the sole desktop control.
- Full tests, type diagnostics, root and project-base builds, links, reading and payload budgets are run against this batch.
- Before-change visual evidence: user desktop screenshot plus actual cloud browser homepage at wide and narrow widths.
- Local static preview was attempted at 127.0.0.1:4321 in cloud Chromium and returned connection refused. No restriction was bypassed. Production-DOM tests do not establish layout or real iPhone Safari behavior; live browser visual/interaction checks are required after deployment, before completion is reported.
