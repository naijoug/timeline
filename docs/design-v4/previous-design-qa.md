## 比较迭代

第一轮证据：`desktop-before-qa.png` 与 `comparison-before.png`。

1. [P2，密集节点] 相邻分组靠近分桶边缘时标签重叠，尤其 2025 年模型轨道。
   - 修复：在初步分桶后计算实际标签区间，持续合并相撞分组；所有事件保留在组内，标记数量和日期范围。
   - 复验：`desktop-after-qa.png`、`desktop-final.png`；单元测试检查 160、245、500、850、1200 px 下标签间隔以及条目无遗漏。
2. [P2，主要区域比例] 首轮右侧内容撑长整页，来源和页脚离开设计稿的主要视口。
   - 修复：桌面工作区与视口对应，右侧阅读区独立滚动；版本变化使用可展开说明；优先显示解释与来源。
   - 复验：生产截图中三轨、来源入口与页脚均可见，长内容仍可阅读。
3. [P2，总览标签] Transformer 的说明与所选窗口标签接近并发生挤压。
   - 修复：调整窗口标签的垂直位置；总览按正确年份比例放置。
   - 复验：最终生产截图中标签互不遮挡。
4. [P2，窄屏缩放] 缩小到较长区间时，年份刻度仅按跨度决定，窄屏可能过密。
   - 修复：刻度数量同时依赖可用像素宽度，使用 1/2/5/10/20/50 年间隔。
   - 复验：新增刻度间隔测试，320px 与 375px 页面无横向溢出。

## 必查设计维度

- 字体：字标使用 Georgia 衬线字，界面使用 DM Sans 与系统中文回退；主轨道标题 21px、节点标题 14px、阅读正文 15px，保持与参考相同的层级。不同系统中文字体的字形差异为 P3。
- 布局：顶部横向导航、整段历史总览、年份与地区工具栏、三条共用时间刻度的轨道、约 330px 的右侧详情与底部说明均已实现。桌面主画布左右边距约 40px，标签列 235px。
- 色彩：白底与浅灰分隔线，技术蓝 `#087cf0`、模型绿 `#079b79`、应用橙 `#ed7525`；选中态保留颜色与文字/环形标记的双重提示。
- 图像与图标：参考没有照片或插画资产。字标是可选择的界面文字；CPU、层叠、网络、地球、搜索、缩放等使用已有 Lucide 图标。时间线标记属于功能性数据可视化，不是用代码伪造的图像背景。
- 文案：保留三条主线名称与中文界面，移除旧版大幅标题和侧栏。原图中的“今天”改为“最近”，避免把编辑资料集误作实时数据服务；未制造账号和语言切换功能。
- 阅读与状态：节点组显示数量和真实日期范围，详情可查来源、版本变化与组内事件。搜索、空结果、当前筛选、关闭详情、范围边界均有对应状态。

- 全球切换到中国团队，模型与应用结果正确分流。

- 在生产预览重复中国团队 + MiniMax Agent 搜索/选择/刷新流程；该阶段浏览器无新增 error/warn。

## 有意保留的差异与边界

- 纠正原图把 Mixtral、Gemini、Qwen、Kimi 等模型放在技术轨道，以及把 ReAct 放在应用轨道的示意归类。
- 1943–2026 总览采用实际比例，2023–2025 的选区因此比参考图窄；不挪动历史事件来填满画布。
- 更多全球数据通过聚合保留，默认绘制的点不是资料库条目总数。聚合点是组内位置均值，不声称它是某条具体事件的精确日期。
- 小屏将右侧详情放到下方，选中事件后可进入阅读区；手机样式没有独立来源图，按可用性验收。
- 不声称完成全站无障碍认证或全部外站在所有网络中的可用性验证。无剩余阻塞性的 P0/P1/P2 设计项。
