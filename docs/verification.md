# MVP 验证记录

验证日期：2026-09-29。环境：Node.js 22.22.3、Astro 7.3.5，本机浏览器。

## 自动检查

- `npm run check`：0 errors / 0 warnings / 0 hints。
- `npm test`：8 项逻辑测试通过。覆盖内容关联、非法日期/来源、日期精度、URL 状态往返、组合筛选、搜索、排序、同次公告的多事件。
- `npm run build`：通过；生成 128 个静态页面。
- `npm run check:links`：检查 128 页上的 2,303 个内部链接，全部解析到存在的构建文件。
- 内容图校验：80 个事件、23 个对象、57 个来源、6 条明确关系。56 个来源被事件直接引用，另一个由产品页引用。

## 浏览器验证

- 桌面全史默认展示 26 个里程碑，切换全部后展示 80 个事件。
- 搜索 Muse 得到一条记录；展开后显示原始来源链接。
- 独立事件页显示正确内容和月份精度。
- 返回链接恢复查询、密度选择和事件锚点。
- Claude 家族筛选显示 12 个已收录模型事件；Sonnet 4 版本详情显示比较基线、变化、限制和同次发布关联。
- 在 320px 视口组合筛选年份与公司，刷新后查询条件和结果数量恢复。
- 不存在的关键词显示空结果，可清除筛选。
- 手机导航、筛选与卡片不产生水平溢出；375px 和 320px 均检查过，桌面恢复为默认视口。
- 生产构建上验证查询深链接、事件标题点击、键盘访问、返回状态、Manus Studio 与 Manus 的关联。

开发过程中发现并修复：窄屏导航溢出、换行标题点击区域偏小；依赖和构建更新后的开发模块缓存问题通过重启开发服务恢复，最终交付以生产预览再次验证。
