# 2026-11-02 08:00 UTC：移动端阅读路径定位

本轮基于 main `28a680e192e8e863958df9b744b46372faf92814`。仅改进共用阅读器的横向路径选择器，不改变事件、来源、线路成员、日期范围或既有路由。

## 行为

- 进入独立子线或恢复线路选择时，若当前没有完整可见的已选路径，横向展示最近的已选卡片。
- 多选时只要有一条已选路径可见，就不自动滚动；用户正在操作路径控件时保留焦点和横向位置。
- 仅修改路径容器的水平滚动，不调用元素 `scrollIntoView`，不移动页面纵向位置。采用即时定位，不引入动画，也适用于减少动态效果偏好。
- 普通搜索、排序及筛选不触发重新定位；用户可以横向浏览其他路径，不会被持续拉回。
- 不需要横向滚动的桌面网格保持原状。
