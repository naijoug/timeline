# 通用时间线重构：第一轮交付

日期：2026-09-30。

## 实现边界

首页成为主题目录，保留 AI 发展史，新增中国历史。中国历史包含 34 个朝代与时期、20 个精选事件和 14 份资料来源。唐代为详细样例，宋辽夏金为并存关系与跨政权事件样例；其他时期多数仍是骨架，页面明确标注，不能视为完整通史。

浏览路径：主题首页 → 中国历史 → 朝代／时期 → 类别筛选 → 事件详情。独立战役专题支持跨朝代浏览。时期、类别、关键词、日期范围、聚合详情、选中事件及展开状态可在 URL 中恢复；完整事件页带受同源路径约束的返回地址。

## 代码边界

- `src/core/`：不导入任何具体主题。提供结构类型、时间坐标、区间查询、分类／关键词筛选、URL 往返、聚合、条带几何、并行布局及内容引用校验。
- `src/topics/ai/`：迁入原 AI 数据与规则，适配器将事件投影为通用模型。原 `src/data/` 与部分 `src/lib/` API 保留兼容导出。AI 三轨 UI 和模型变化详情保留专门展示，但日期、筛选和聚合已复用 core。
- `src/topics/china-history/`：时期、事件、来源及主题配置。一个事件可关联多个时期；`periodIds` 表示明确的内容归属，时间相交本身不会自动建立归属。
- `src/components/timeline/Explorer.tsx`：接收 Catalog，不导入具体历史数据。主题快捷入口与时期路由段来自配置。共用时期浏览器仍以时期／事件阅读为中心；特殊领域详情由主题路由提供。
- `src/pages/china-history/`：静态生成总览、时期、战役专题与事件页。AI 已有路由和 ID 保留，旧根路径的 AI 查询链接转至 `/ai/`。

主题页按需载入自己的数据；中国历史客户端不导入 AI 事件库。无数据库、账户、远端模型或自动抓取任务。

## 日期与历史分期

内容年份 -1 为公元前1年，1 为公元1年，拒绝0年。内部连续坐标0对应公元前1年；URL 与显示使用历史年份。公元前刻度按整百／整千的历史年份对齐。

部分日期以已知区间中点定位，保留原始精度；持续事件通过区间交集筛选。`uncertain` 可表达不确定日期区间，与 `duration` 持续过程分开。月日计算按前推公历，原始历法未经核对不能直接当作现代月日。

时期树只组织阅读，不代表政权的隶属关系。明确的并存时期展开为同刻度的独立条带；总览同年交接可以共用主线，超过边界年的重叠放入并行行。按年记录的边界不能解释为精确交接日。

秦汉起止、辽的建国起点、宋的终点、元的定国号与完成征服、清的入关与建国等口径在时期页说明。唐代分期包含武周并明确标注。早期近似纪年不伪装为确定日期。

## 后续内容工作

本轮为可运行的首批交付。扩充事件仍需逐条核查资料，特别是早期年代、不同纪年口径、战争与战役边界。内容规模继续增长时再考虑分片加载、全文检索与编辑工作流；当前不引入这些服务。

人工内容校核与自动结构检查是不同保障：构建校验不能证明史实无误，也不替代外链的实时可用性验证。
