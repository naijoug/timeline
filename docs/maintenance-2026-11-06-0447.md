## 暴露面与剩余边界

本站生成静态 Pages，没有常驻 Node 后端。应用代码没有导入上述库处理访客输入；字体自行托管。`dependencies` 中的构建工具不等于浏览器生产包。这次核查没有发现访客可达的利用路径，但不能据此声称开发工具毫无风险。

- fast-uri 位于开发检查链，涉及 URI 的协议、主机和相对路径处理。
- source-map-js 涉及恶意索引 source map 导致的资源耗尽，主要影响构建或配置处理。
- Undici 涉及特定 HTTP、TLS、SSE、WebSocket 和缓存用法。没有远程字体配置，但 unifont 在代理环境下仍可能初始化 dispatcher，不能写成「完全没有加载」。npm 包更新不会更新 Node 自带的 Undici。
- Vite 的公告针对开发服务器及编辑器启动等功能。本地127.0.0.1绑定降低网络暴露；关闭 Astro 工具栏并不等于移除所有开发端点。不要把开发服务器用于生产。
- Zod 涉及校验超大无效集合时的内存耗尽；本站无接收这类访客输入的 Zod 接口。

**仍保留的内嵌代码：** `magicast@0.5.5` 的发布包声明 `inlinedDependencies.source-map-js = 1.2.1`，其 builders 文件包含旧实现。更新独立的 source-map-js 或添加 npm override 都不会重写这部分代码。本次 registry 核查中，magicast 最新版本仍为0.5.5。Astro 仅从 `astro add` 配置编辑分支导入 magicast，本站常规构建与页面不调用这个操作。不要向该工具传入不可信的 source map／配置转换输入；后续应核查上游重新构建的版本。即使 npm audit 为零，也不能将这个剩余边界写成已修复。

已有 Undici 8.11.2 和本次8.12.2均要求 Node.js ≥22.19.0，因此将开发文档原来的22.12+说明修正为22.19+；这不是本次新增的运行时门槛。现有 CI 继续使用 Node.js 22 的最新补丁版。
