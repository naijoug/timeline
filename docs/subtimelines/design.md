# 子时间线数据模型

## 一份事件，多条阅读路径

`TimelineEvent` 继续保存唯一的事实、日期精度、实体、类别、标签与来源。新的 `TimelineDefinition` 保存稳定 ID、主题、标题、说明、路径、可选父级以及 `entries`。每项只保存 `eventId`、本线的重要性和可选编辑语境；事件本身没有 `timelineIds`，不维护双份归属。

- 类别用于主要类型，标签用于检索；二者不等于子时间线。
- `entries` 是人工维护的唯一成员表。同一事实可以出现在多条线。
- 父级只组织阅读导航，不继承子级事件。主线也是独立策展，不是子线的自动总和。
- 合并阅读按事件 ID 取并集，只渲染一次事实。关键节点按选中线路的 `importance` 判断，任一选中线视为关键就保留。
- 不按日期顺序推断因果。`context` 是编辑阅读提示，不覆盖事件事实与证据。

## 首批迁移

既有 Collection 升级为 TimelineDefinition；保留原 `/collections/` 路径与导出名称，目录的规范属性改为 `timelines`。不再维护 `Collection.eventIds`。

- AI：49 个发展里程碑、190 个模型发现与迭代节点、46 个 Agent 产品节点；原有两个专题保留。
- 喜爱作家：刘慈欣、紫金陈、马伯庸的现有作品年谱；不是完整生平或完整书目。
- 中国历史：四条既有专题，含战争转折；冻结显式成员，新增类别事件不会无声加入专题。
- 成语故事尚未补录：战役事实、成语典故与成书年代须分别核对，不以现代释义杜撰古代日期。

这次只重组现有资料，没有增加历史事实，也没有把既有来源核查日期当成本轮全部复核。2022 年 ChatGPT、ReAct、MCP、Skills 不是 Agent 产品发布；模型论文、预览、API 和权重开放不合并为一个日期。

## 兼容与约束

保持静态站点和轻量客户端索引；正文、详细来源与关系不进入事件索引。`TimelineDefinition` 是轻量阅读导航数据。校验覆盖重复成员、未知引用、主题、路径、重要性、默认线、未知父级与父级循环。

未来若确实需要动态规则，再引入经过版本化的 includes/excludes；当前不引入数据库、规则引擎、自动继承或双向成员字段。
