# timeline

一个按时间脉络探索知识的网站，将重要事件、背景解读和资料来源串联起来，帮助理解技术、历史与作品的发展。

目前包含四个主题：**AI 发展史、编程语言、中国历史、作家作品**。支持关键词搜索、分类与年份筛选，以及带来源的独立事件详情；适配桌面和手机，提供浅色与深色外观。

项目使用 Astro、React 和 TypeScript，支持本地运行和静态部署，无需数据库、账号系统或运行时模型 API。内容是持续扩充的精选资料集，不追求穷尽所有事件。

## 本地运行

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://127.0.0.1:4321/。
